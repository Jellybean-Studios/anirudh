# Game sources

Updated October 21, 2026. The arcade contains five embedded games: Drift Boss, Escape Road 1, Escape Road 2, OvO, and Cookie Clicker.

## Existing players

Drift Boss and Escape Road 1 retain the user-provided JasonGamesDev players. Escape Road 2 retains its existing public alternate player. These three entries are unchanged.

## OvO

OvO uses the public Construct Arcade player published at [games.construct.net/62576/latest](https://games.construct.net/62576/latest). The catalog links back to the [Construct game page](https://www.construct.net/en/free-online-games/ovo-unblocked-62576/play), which provides the official embed snippet and terms for embedding. No game files, SDKs, or publisher checks are modified.

## Cookie Clicker

Cookie Clicker uses the public GitHub Pages demo published by [ozh/cookieclicker](https://ozh.github.io/cookieclicker/), with the repository credited in the catalog. The repository describes itself as an educational mirror and points to the original game at Orteil’s domain; its files are not copied into this site. The card uses the published Cookie Clicker icon.

## Validation

All five entries have unique IDs and HTTPS player URLs, valid local covers, and embed mode. The catalog no longer includes the previous local classics or GameMonetize entries. School-network access remains unverified and can still depend on the network filter. Some official game hosts may refuse iframe embedding, in which case the host itself must be opened directly.
